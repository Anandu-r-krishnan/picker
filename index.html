Make a client link

One Drive folder per project. Each sub-folder shows up as its own roll, so you can split a shoot into Haldi, Ceremony, Reception and so on.

  1. Upload the photos and videos to a Google Drive folder. Low-res JPEG exports and video proxies load fastest; keep the same file names as your originals.
  2. Paste the folder link here. For a private gallery, add the client’s Gmail and keep “Make private” ticked: the folder is shared only with that account, and the client signs in with Google to open it.
  3. For an open gallery, leave the Gmail empty and share the folder in Drive as Anyone with the link · Viewer.
  4. Send the client link. When they press Send you get an email, a row per file in your selections sheet, and a folder of shortcuts to the picked files.
